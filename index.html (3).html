🔎 Mistake Analysis

FLO Spark Fusion looks at common error patterns so students can understand why an answer went wrong.

🧮

Calculation Error

A mistake happened while working with numbers or operations.

🧠

Concept Error

The main idea or meaning of the topic was misunderstood.

📐

Formula Error

The wrong formula or rule was selected or applied.

🔍

Interpretation Error

The question or information was interpreted incorrectly.

📚

Knowledge Gap

The student needs to learn or revise the underlying fact or skill.

How it works

Each demo question has a predefined error pattern. When a student submits a wrong answer, the system displays the associated pattern and a helpful hint.
